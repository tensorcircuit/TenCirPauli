# Lie-closure study

This manual study explores the dynamical Lie algebra generated by anti-Hermitian Pauli operators. The `word` mode uses the fact that a nonzero commutator of two Pauli words produces one Pauli word up to a scalar. The `sum` mode treats Pauli sums as real vectors in the anti-Hermitian basis `-iP` and uses numerical rank to decide independence. The result reports the generated dimension separately from the number of candidate brackets and marks bounded runs as incomplete.

Run the bounded chain workload and its independent pure-Python dictionary baseline:

```bash
conda run -p .conda python examples/research/lie_closure/run_tencirpauli.py
conda run -p .conda python examples/research/lie_closure/run_python_dict.py
```

Run exact small reference cases:

```bash
conda run -p .conda python examples/research/lie_closure/run_tencirpauli.py --case su2 --mode word --max-dimension 8
conda run -p .conda python examples/research/lie_closure/run_tencirpauli.py --case su4 --mode word --max-dimension 32
conda run -p .conda python examples/research/lie_closure/run_tencirpauli.py --case sum2 --mode sum --max-dimension 64
```

The chain case is intentionally bounded because a generic controllable `n`-qubit system can approach the ambient dimension `4**n - 1`. Results are printed only; external-library comparisons and any later regression benchmark should reuse these fixed workloads without entering the default example run.
